| 2026-08-10 | Stored `referrer` (1024-char cap) is out of scope for customers/data_request & customers/redact | It's page-level web-standard referrer data with no linkage to any Shopify customer record — the app stores zero customer PII, so those webhooks correctly no-op. | 2026-08-10 | CSV import applies per-row via createRedirect (500 rows/file cap), not Shopify's native urlRedirectImportCreate/Submit | Native bulk import verified to exist on 2025-10 (staged upload + async submit) but gives no per-row error report, no DB mirror, no 404 auto-resolution, no source attribution, and needs polling. | 2026-08-10 | Plain CSV import/export ungated (free-plan 25-redirect cap still applies); migration importer (auto-match + confidence) stays MIGRATION-gated | FREE spec text doesn't exclude CSV; the cap already limits value extraction, and easy import drives adoption. The paid differentiator is the matching intelligence, not file upload |
| 2026-08-10 | CSV parser hand-rolled (~60 lines), no papaparse dependency | Two known columns, no multi-line quoted fields (URLs can't contain newlines), extra columns ignored for WordPress/BigCommerce export compatibility; 12 unit tests cover quoting/BOM/CRLF/dupes. A dependency would exceed the problem |
